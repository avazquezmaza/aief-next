# Specification

## Goal

Align version string in package files with AIEF 3.1.

## Requirements

- `package.json` version is "3.1.0"
- `cli/package.json` version is "3.1.0"
- `package-lock.json` version is "3.1.0"

## Acceptance Criteria

- [x] package.json updated to 3.1.0
- [x] cli/package.json updated to 3.1.0
- [x] package-lock.json updated to 3.1.0
- [x] `aief --version` outputs `aief 3.1.0`
