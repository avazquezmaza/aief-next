# Specification

## Goal

Turn the AIEF 4.0 simplification into durable, human-approved decisions and implementation-ready prerequisites — without writing application code.

## Requirements

- One decision per component in scope (D1–D8), each with options, a recommendation and the
  files, flags, tests and docs it affects.
- An ADR-038 draft, recorded in `knowledge/decisions.md` only after approval.
- The follow-up implementation Change identified.

## Acceptance Criteria

- [x] Context, Business/Product Constraints and Known Requirements are captured.
- [x] Open Questions are answered or explicitly deferred.
- [x] Every Decision Required has a Recommendation and an explicit human Decision.
- [x] Approved decisions are recorded in knowledge/decisions.md.
- [x] Implementation Prerequisites and Follow-up Changes are listed.
- [x] Evidence updated.
