# Specification

## Goal

Turn the assistant-native skill into durable, human-approved decisions and implementation-ready prerequisites — without writing application code.

## Requirements

- One decision each for skill content, installation, updates, the `AGENTS.md` split, and
  `aief prompt` (D1–D5), with options and a recommendation.
- An ADR draft recorded in `knowledge/decisions.md` only after approval.

## Acceptance Criteria

- [x] Context, Business/Product Constraints and Known Requirements are captured.
- [x] Open Questions are answered or explicitly deferred.
- [x] Every Decision Required has a Recommendation and an explicit human Decision.
- [x] Approved decisions are recorded in knowledge/decisions.md.
- [x] Implementation Prerequisites and Follow-up Changes are listed.
- [x] Evidence updated.
