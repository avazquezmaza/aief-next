# Release v4.2.0

## Upgrade notes

- **New command `aief update`** (ADR-040). After upgrading AIEF, run it in a project to replace
  `AGENTS.md` and installed `aief-change` skills that are still unmodified AIEF versions. An edited
  file is never written; a missing one is not created (`aief bootstrap` and `aief skill install` do
  that). It also lists skill-capable assistants without the skill. Review with `git diff`; AIEF
  never commits.
- **`aief doctor`** now reports an older unmodified `AGENTS.md` under "AIEF-shipped files" (renamed
  from "aief-change skill") and points every older unmodified file to `aief update`.
- Projects bootstrapped before 4.0 still carry `AGENTS.md` text about tracks and gates, which were
  removed in 4.0. `aief update` replaces it when the file was never edited.

## Summary

One Change since 4.1.0 (0160): `aief update`, a shared shipped-file classifier
(`core/domain/shipped-file.js`) used by `AGENTS.md` and the skill, the `doctor` report, docs,
ADR-040, version 4.2.0 and these notes.

No runtime dependency added; `@aief/cli` remains dependency-free.
