# Release v4.3.0

## Upgrade notes

- **New command `aief guardrails install`** (ADR-041). Adds Claude Code `permissions.deny` rules
  that keep credentials (`.env`, `~/.aws`, `~/.ssh`, keys, Terraform state, …) out of an
  assistant's reach, to `.claude/settings.json` (`--local`: `settings.local.json`). Only adds rules;
  never removes or changes yours. `--approval-hook` also installs a PreToolUse hook that refuses an
  edit checking, abandoning or deleting a `(human)`/`(review)` item. A shell command can still
  bypass it: a mitigation, not a guarantee.
- **Gemini CLI** (ADR-042). `aief guardrails install --assistant gemini` installs the same approval
  guard as a `BeforeTool` hook in `.gemini/settings.json`. Gemini has no project-level deny list,
  so no credential rules are added for it. `aief skill install gemini` installs the `aief-change`
  skill at `.agents/skills/aief-change/SKILL.md` — the same file Codex uses — and
  `aief prompt gemini` then points to it instead of inlining the procedure. Gemini runs project
  skills and hooks only in a trusted folder.
- **Behavior change: `aief new-change --type`.** The type you pass is now written to
  `change.md` (it always said `General` before) and normalized (`FIX`, `bugfix`, `Definición`). An
  unknown type, or `enrichment` (use `aief enrich`), now fails before any branch or file is
  created — it used to succeed as a General Change.
- **Change IDs in parallel work.** `new-change`, `analyze`, `propose`, `enrich` and `bootstrap` now
  skip numbers already used in another worktree's `changes/` or by an AIEF branch
  (`<type>/<NNNN>-<slug>`, local or already fetched). Read-only git; nothing is fetched. Two clones
  that never fetched each other's branches can still collide; `aief verify`/`status` keep
  reporting that.
- **`## Type` is a closed list**: `general`, `analysis`, `definition`, `enrichment`, `fix`,
  `feature`, `documentation` (case, accents and common aliases accepted). `verify --strict` names
  an unknown value; it behaves as `general`.
- `aief doctor` reports Claude Code guardrails when `.claude/` exists and the Gemini guard when
  `.gemini/` exists.
