# Release v3.3.0

## Summary

Thirteen Changes since 3.2.0 (0090–0103):

- **Expert Definition Skills validation round** (0090–0094): `context.definitionEnrichment`
  exposes a Definition Change's own Known/Missing sections to Skills; two instructions-only
  expert Skills, `architecture-definition` and `data-definition`, validated individually against
  realistic imperfect projects and together for domain coexistence on the same Change; a design
  review confirmed durable-knowledge access stays per-Skill-instruction rather than shared
  context.
- **Manifest/change.md status drift detection** (0095): `aief status` and `aief verify` now
  surface — never reconcile — a manifest-backed Change whose `manifest.status` disagrees with its
  own `change.md` `## Status`.
- **Usability validation and ADR-015 thaw** (0096–0097): Change 0042's usability protocol
  executed (pilot + five scored sessions), consolidated into evidence; the project owner's
  explicit decision to lift the remainder of ADR-015's freeze (Candidate DELETE/ARCHIVE, Type↔Track)
  recorded as governance.
- **Skills catalog expansion** (0098, 0100): 20 new stack detectors (Python, Go, Rust, Spring,
  Vue, Angular, Svelte, MongoDB, Redis, GraphQL, Docker, Kubernetes, Vercel, Netlify, Stripe,
  Supabase, Firebase, React Native, Kafka, RabbitMQ) plus 3 new Skills (`payments-reviewer`,
  `container-deployment-reviewer`, `python-backend-architecture`); the generic `python` detector
  specialized into `django`/`flask`/`fastapi`.
- **CLI polish** (0099): three CLI error messages (`resolveImplicitChange()`, `createChange()`,
  `initProject()`) made actionable, matching the codebase's existing "state the problem, then the
  fix" convention.
- **Documentation accuracy** (0101–0102): 4 dangling references to docs consolidated away by an
  earlier documentation Change, repointed to their current home; `docs/workflow.md`'s Skills
  Runtime section corrected from "Four Skills" to the actual 5 (it had omitted
  `adversarial-review`, shipped since Core 3.0).
- **Release** (0103): version bumped to 3.3.0 in `package.json`/`cli/package.json`/
  `package-lock.json`.

No breaking changes, no new subsystem, no manifest field added, no ADR modified.
