# Release v4.1.0

## Upgrade notes

- **AIEF now ships a native `aief-change` skill** (ADR-039). `aief bootstrap` installs it for the
  configured assistant (`--assistant <id>` or `knowledge/assistant.json`), or for Claude Code
  (`.claude/skills/`), Kiro (`.kiro/skills/`) and Codex (`.agents/skills/`) when none is configured.
  Gemini CLI and Cursor have no skill mechanism and get the procedure in `aief prompt`'s output.
- **New command `aief skill install [assistant]`** for projects bootstrapped before 4.1, or to
  refresh a copy. It rewrites only a missing file or an unmodified older AIEF version; an edited
  copy is never overwritten. Earlier copies of the skill from this repository are recognized and
  updated.
- **`AGENTS.md` keeps policy only** (208 → 118 lines). The workflow steps, completion checklist and
  evidence guidance moved to the skill. A project picks up the new `AGENTS.md` only when it is
  missing at bootstrap; to adopt it, replace your copy with the template by hand.
- **`aief doctor`** lists each installed skill and flags an unmodified older copy or an edited one
  older than AIEF's.
- **Passive assistant detection** ignores an unmodified AIEF-installed skill, so installing all
  three does not make a project look like a Kiro project.

## Summary

Two Changes since 4.0.0 (0158–0159):

- **Definition:** how the skill ships and how `AGENTS.md` splits into policy and procedure; ADR-039
  (0158).
- **Implementation:** skill template, installer, `aief skill install`, `bootstrap --assistant`,
  `doctor` report, `prompt` procedure block, `AGENTS.md` split, docs, version 4.1.0 and these notes
  (0159).

No runtime dependency added; `@aief/cli` remains dependency-free.
