# Release v3.5.0

## Upgrade notes

- **A `(human)` or `(review)` approval marked `[-]` now blocks `aief close`** and is reported by
  `aief verify --strict` (0150). Before, `[-]` resolved it like any other task. Check the box, or
  remove the label and say why. `(gate:<id>)` lines already worked this way (ADR-037); ordinary
  `[-]` tasks are unchanged.
- **`aief close` prints "Approvals relied on:"** with every checked `(human)`/`(review)`/
  `(gate:<id>)` line (or `none`) when readiness passes, with or without `--yes` (0150).
- **`aief verify --strict` adds a notice** for an Analysis or Definition Change with no `(human)`
  line. It is a warning; the verdict does not change (0150). Plain `verify` is unchanged.
- **New Skill `protocol-security-reviewer`**, recommended when the new `websocket` (`ws`,
  `socket.io`, `socket.io-client`) or `grpc` (`@grpc/grpc-js`, `@grpc/proto-loader`, `protobufjs`)
  detectors, or the existing `graphql` detector, match `package.json` dependencies (0151). Projects
  using these get one more Skill in `aief prompt`; nothing else changes.

AIEF still does not verify who checked an approval. `docs/security-model.md` describes the platform
controls teams can add (branch protection, a required review from a different account, CODEOWNERS
on `changes/**`, an assistant token that cannot approve or merge) and the accepted residual
risk (0149, 0150).

## Summary

Six Changes since 3.4.0 (0148–0153):

- **Governance:** analysis of approval-label identity with options for the owner (0149), and its
  decision implemented: `[-]` no longer resolves `(human)`/`(review)`, `close` shows the approvals
  it relies on, `verify --strict` notices an Analysis/Definition Change without a `(human)` line
  (0150). `AGENTS.md`, its template and the governance conventions say the same.
- **Security documentation:** `docs/security-model.md` now describes numeric Change-ID collisions as
  detected by `verify`/`status`, not open (0148), and records the approval-identity residual risk and
  team platform controls (0150).
- **Skills:** `protocol-security-reviewer` with WebSocket/gRPC/GraphQL security context (TLS,
  Origin checks, no credentials in URLs, server-side gRPC auth, introspection/reflection off in
  production, query limits), and `websocket`/`grpc` detectors (0151).
- **Repository navigation:** `changes/README.md` indexes every Change by release; history docs
  aligned with ADR-032; 152 MB of ignored local artifacts removed from the maintainer's working copy
  (0152).
- **Release:** readiness audit, version 3.5.0 and these notes (0153).

No ADR added. No runtime dependency added; `@aief/cli` remains dependency-free.
