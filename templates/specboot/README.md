# SpecBoot templates

> **Conceptual reference, not supported in AIEF 4.0** (ADR-038). AIEF no longer reads a project's
> `ai-specs/` directory.

Reference material for a project following LIDR/SpecBoot conventions alongside AIEF. The files in
this directory are never copied or read automatically by any `aief` command — they are visible
templates for a human to adapt by hand (`agent-file.md`, `profile-prompt.md`).
